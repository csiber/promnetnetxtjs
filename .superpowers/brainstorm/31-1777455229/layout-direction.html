Milyen layout iranyt valasszunk?

A jelenlegi ketoszlopos (sidebar + content) layout helyett egyszerubb, megbizhatobb megoldast keresunk.

Polyak Csaba
Backend / Infra

A) Egyoszlopos, szekcionalt

Minden egymas alatt, teljes szelessegben. A profil kep + nev + kontakt felulon, alatta szekciok: hero, szolgaltatasok, referenciak, kapcsolat. Egyszeruen scrollozhato, mobilon is tokeletesen mukodik.

PromNET

B) Landing page stilus

Klasszikus landing page: fix nav felul, nagy hero szekcioval, alatta szekciok teljes szelessegben. Profi, clean megjelenes. Nem kell sidebar, minden szekcionkent jon egymas utan. A jelenlegi HomePage-hez hasonlo, de sidebar nelkul.

C) Bento grid / kartyas

Modern bento-grid layout: kartya-alapu elrendezes, ahol minden blokk (profil, szolgaltatasok, stack, referenciak, kontakt) egy-egy kartya a racsban. Vizualisan erdekes, egyedi megjelenes. Jol mukodik responsivan is.
